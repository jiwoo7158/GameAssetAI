# GameAssetAI Workspace

Open this directory as the source folder for normal Codex game-asset work.

- `profiles/`: persistent game-specific art and technical rules.
- `config/active-profile.json`: exact active Profile id.
- `config/projects.json`: optional absolute path bookmarks, including `unity-workbench`.
- `config/settings.json`: personal, game-neutral preferences.
- `outputs/`: user deliverables. It is created on demand and may be deleted completely.
- `notes/`: optional personal notes.

Use the installed `gameassetai-workspace` Skill to create/select Profiles and validate this folder.
Do not copy existing game projects into this Workspace.
